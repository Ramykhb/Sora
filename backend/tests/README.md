Install requirements-dev.txt and run `python -m pytest -q`. Unit tests use synthetic images and model-protocol fixtures. API integration tests use SQLite with foreign keys, local object storage, and deterministic substitutes for external inference. Model quality, Postgres vector ranking, real speech and WebRTC transport need a configured integration run; use the evaluation CLI for image/retrieval/answer measurements.

Authentication tests use real salted Argon2id, opaque tokens and SQLite transactions. They cover account registration/login/profile, user/admin permissions, per-user API and WebSocket isolation, refresh rotation/replay/concurrency, expiry, logout and live-stream revocation, password reset/change, email verification, account deletion, login-session revocation, and persistent rate limiting. SMTP delivery is substituted; run with configured PostgreSQL and SMTP to validate those deployment integrations.
