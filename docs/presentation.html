Read the scene. Remember the sign.

  • “What is in front of me?”
  • “What was written on the sign I passed?”
  • English, French and Arabic input/output paths.

Honest uncertainty: no face recognition, unsupported distance claims or assurances that a route is safe.

Consent before capture; selected images expire after 24 hours by default. Users can delete their data earlier.

Two independent processing paths

Phone camera → WebRTC server relay → live dashboard video
Live objects

Newest frame → YOLO → fresh observations → optional spoken alerts.

No OCR or generative model on this path.

Visual memory

Sample → quality/deduplication → enhance → OCR → image/database save → deferred caption and embedding.

Whisper → question → evidence retrieval → vision-language answer → native speech or WAV.

Technology stack

Clients and transport

Expo / React Native · React / Vite · WebRTC / aiortc · TURN · authenticated WebSockets.

Processing and storage

FastAPI · OpenCV · Tesseract · YOLO11n · PostgreSQL / pgvector · RustFS objects.

Whisper speech recognition, Ollama Qwen2.5-VL and Qwen3 embeddings, native mobile speech and eSpeak WAV.

Local Docker deployment. Ollama is limited to two CPU cores for this laptop.

Useful frames become searchable memory

  • Sharpness and brightness checks; perceptual-hash duplicate rejection.
  • CLAHE, denoising and sharpening; OCR fallback removes long sign borders on an analysis copy.
  • Original/enhanced image keys, OCR, boxes, captions, timestamps and embeddings stored together.
  • Time filters plus semantic and lexical retrieval; objects and text remain searchable when captions are skipped.

Bounded queues prevent slow descriptions from creating an unlimited backlog.

Answers carry their evidence

  • Text-reading questions use retained OCR; visual questions include camera images in a numbered contact sheet.
  • Only supplied frame IDs can be cited; evidence is checked again after inference.
  • Weak, unavailable or stale current-view evidence produces uncertainty.
  • Phone and dashboard share status, retained frames, questions and feedback.
  • Fresh alerts interrupt answer speech; paused or expired observations are not spoken.

Evidence, with explicit limits

  • 131 backend tests: ownership, retention/deletion, inference scheduling, streaming, OCR and live-alert independence.
  • 18 mobile tests; lint, typecheck and iOS JavaScript export.
  • 15 dashboard tests and production build.
  • Real-service test: generated signs, continuous publisher/viewer video, OCR, semantic retrieval, multilingual answers, speech, feedback and deletion.

Use the checked-in acceptance report and validation notes for final measured values and any failures.

Synthetic checks measure functionality; they are not human answer-accuracy or obstacle-recall results.

Latency determines the architecture

  • A slow vision-language model cannot be the trigger for immediate object alerts.
  • Freshness matters: an old observation must not become a current walking instruction.
  • The 80-class detector does not include doors or stairs. Closed-door VLM interpretation remains best effort.
  • Server timing excludes phone capture, network and audible speech onset.
  • Physical iPhone accessibility, real-world recall and human answer ratings require representative consented testing.
